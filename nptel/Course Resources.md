**Index:** [[NPTEL Index]] · **Hub:** [[Graph Theory]]

## ❌ There are no slides for this course

I checked the official NPTEL archive. For **all 40 lectures** of course 106108054 it lists **"PDF unavailable"** — the course was published as **video only**. Chandran taught from a blackboard, so there was never a slide deck to publish.

The per-lecture PDFs floating around on mirror sites are **auto-generated speech transcripts**, not slides, and none of them were retrievable anyway.

**Conclusion: the videos are the lectures. For written material, use the books.**

## ✅ The official syllabus

[Syllabus PDF (archive.nptel.ac.in)](https://archive.nptel.ac.in/content/syllabus_pdf/106108054.pdf)

Short, but it gives the **official hour allocation** — which tells you what Chandran considered weighty:

| Topic | Hours | | Topic | Hours |
|---|---|---|---|---|
| Vertex cover | 1 | | Perfect graphs | 2 |
| Matchings | 3 | | Planar graphs | 3 |
| Path cover | 1 | | Other special classes | 2 |
| Connectivity | 3 | | Network flow | 3 |
| Hamiltonicity | 3 | | Introduction to minor theory | 3 |
| Vertex colouring | 4 | | Probabilistic methods: basics | 3 |
| Edge colouring | 3 | | Markov, Chebyshev inequalities | 1 |
| Other colouring problems | 2 | | Lovász Local Lemma | 2 |
| | | | Random graphs | 1 |

**Total: 40 hours.** **Vertex colouring gets the most time (4h)**; matchings, connectivity, hamiltonicity, edge colouring, network flow and minor theory get 3h each.

### ★ The course is built on Diestel

The official reference list has only **two** books:

1. **R. Diestel**, *Graph Theory*, Springer-Verlag, 2nd ed., 2000
2. **N. Alon & J. Spencer**, *The Probabilistic Method*, Wiley, 2nd ed., 2000 — for lectures 35–38 only

> **This is the useful bit.** Chandran's course runs on **Diestel** — the same book my problem sets come from ([[Assignment 1]]). So the videos and my assignments share a source, and Diestel *is* the written companion to these lectures. There's no need for a third text.
